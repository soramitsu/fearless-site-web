### Overview
4.2.0 graduates from beta with a handful of last‑minute polish items: Android 15 readiness (compile/target toolchains + CI installers), WalletConnect crash fixes for builds that excluded the legacy Pay module, and refreshed sr25519 native libraries that work with the new `shared_utils` package. These changes landed after the beta cut and are now part of the stable release.

### What’s New in 4.2.0
- TON support is now public across send/receive, asset details, and explorer entry points so TON wallets work without feature flags.
- Coinbase joins the provider roster along with a refreshed price service and remote asset sync, improving fiat ramps and data freshness.
- All WalletConnect experiences moved to the Reown SDK, covering session management, signing, and disconnect flows for Substrate and EVM dapps.
- The Android toolchain (AGP/Kotlin, compile/target SDK, NDK) was upgraded to meet Google Play’s current policy window.
- CI/CD picked up NDK r28 verification, native library integrity checks, improved Jenkins ordering, and deterministic alignment printing.
- Fixes include closing promotional banners reliably (FLW‑5177), improved Ethereum recipient validation/warnings, and polish across confirmation screens and other UX hotspots.

### Additional Stabilization 
- Relaychain staking: repaired the active-era cache and configurator routing so staking status, rewards, and flows update immediately after network changes.
- TON stack hardening: tightened TonConnect URL validation/normalization, introduced indexer RPC models, improved pagination/fee cursors, and added new tests so wallet history, transfers, and dapp connections remain resilient.
- Build/signing reliability: aligned AGP/R8 and Gradle wrapper versions, enforced CI keystore checks, stabilized runtime/service state, and refreshed encryption utilities for more deterministic release builds and lint/signing passes.
- Localization refresh: merged updated translations across Indonesian, Japanese, Portuguese, Russian, Turkish, Vietnamese, Chinese, and base strings so the UI reflects the latest copy.
-  Ready for Android 15: the app now targets API 36, and our CI/local tooling installs the matching SDK.
- WalletConnect stability: builds that exclude WalletConnect Pay no longer crash during WalletKit initialization.
- sr25519 reliability: rebuilt native libraries, fix account creation/import when using the latest shared_utils package.
- Additional polish: lint is a hard gate again, and Gradle shims keep fearless-utils integrations stable.
